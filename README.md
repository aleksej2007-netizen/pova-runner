# Pova Runner

Раннер в духе Chrome Dino, но с 3D-эффектом: параллакс-фон, перспективная
"дорога" со сходящимися линиями и объёмные (псевдо-3D) спрайты.

- Игрок — стилизованная иконка смартфона.
- Наземные препятствия — значки высокой температуры (перепрыгивать).
- Летающие препятствия — обобщённая иконка геймпада в стиле батл-рояля
  (приседать через свайп вниз).

Управление: тап — прыжок, свайп вниз — присесть.

## Сборка APK через GitHub Actions

Такая же схема, как в прошлый раз:

1. Создай новый репозиторий на GitHub (например `pova-runner`).
2. Загрузи содержимое этой папки через Termux:
   ```
   git clone https://github.com/<логин>/pova-runner.git
   cd pova-runner
   # скопируй сюда файлы проекта
   git add .
   git commit -m "init"
   git push
   ```
3. На вкладке **Actions** сборка запустится автоматически.
4. Через несколько минут скачай APK из раздела **Artifacts**
   (`pova-runner-debug-apk`).

Минимальная версия Android — 8.0 (API 26).
